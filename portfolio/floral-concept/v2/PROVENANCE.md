# Происхождение изображений v2

Концепт «Тихий сад», каталог `portfolio/floral-concept/v2`.
Фотографии клиента, портреты и логотипы не используются. Снимки v1 сюда не копировались.

Цветы сделаны для этого концепта как отдельные студийные кадры на ровном фоне (зелёный для пиона, розы и ранункулюса, пурпурный для ветви) и вырезаны локально по цвету фона. Это плоские изображения с тенью в вёрстке, не трёхмерная модель и не сцена WebGL.

| Файл | Что на картинке |
| --- | --- |
| assets/flowers/peony.png | бледно-розовый пион |
| assets/flowers/rose.png | пыльно-розовая роза |
| assets/flowers/ranunculus.png | белый ранункулюс |
| assets/flowers/foliage.png | ветвь эвкалипта |

Шрифты Cormorant Garamond и Manrope: OFL, файлы Fontsource 5.2.8.
Других изображений в v2 нет.
