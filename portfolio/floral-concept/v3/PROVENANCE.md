# Происхождение изображений v3

Концепт «Тихий сад», каталог `portfolio/floral-concept/v3`.
Фотографии клиента не используются. Снимки v1 и файлы v2 не переписывались: четыре выреза v2 скопированы в v3, остальные сделаны отдельно.

Все цветы — отдельные студийные кадры на ровном фоне и локальный вырез по цвету фона. Зелёный фон у цветков без листьев, пурпурный у зелёных ветвей. Это плоские слои с тенью в вёрстке, не трёхмерная модель.
